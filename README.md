# Chlorination of a polyamide membrane with molecular dynamics

System preparation and raw data collection with GROMACS are in `direct_chlorination` and `hydrolyzed_chlorination`. 
These are incomplete - full details are archived on PetaLibrary at University of Colorado Boulder. Contact Michael Shirts full data.

Analyzed data and figures for paper are in `paper`. All figures can be generated with `plot_chlorination.ipynb`.

`scripts` contains necessary classes for building and analyzing the chlorinated membranes.
